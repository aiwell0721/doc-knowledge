# VLM 双模型对比报告（方案 C：约定标记 Markdown）

**样例**：`ai_market_10pp.pptx`（10 页 AI 市场主题，含总分/并列/对比/递进/矩阵结构）

## 3. 结论

### 3.1 标记格式根治 JSON 脆弱性（核心验证通过）

| 方案 | 合规率 | 降级率 |
|------|--------|--------|
| JSON（方案 C 迁移前，GLM 实测） | 11%（89% 非法） | 20%+（修复后仍因未转义引号降级） |
| **约定标记 Markdown（迁移后，GLM）** | **100%** | **0%** |
| **约定标记 Markdown（迁移后，Qwen）** | **100%** | **0%** |

GLM 从 JSON 时代的"89% 非法、修复后仍 20% 降级"跃升至** 10/10 页全部结构化、0 降级**。
纯文本标记彻底消除转义负担，方案 C 的收益在真实双模型上得到验证。

### 3.2 模型差异：GLM 完整输出，Qwen 仅必需标记

- **GLM-4.6V-Flash**：完整输出 `[DK-标题]/[DK-概述]/[DK-结构]/[DK-正文]` 四个标记，
  标题/结构/概述提取成功率均 100%，且结构识别准确（"并列/总分结构"与实际页面一致）。
- **Qwen2.5-VL-7B**：仅输出必需标记（`[DK-标题]` + `[DK-正文]`），跳过可选的概述/结构。
  标题与表格正文 100% 还原，产物**无降级、无渲染问题**——"标记缺省"设计使 Qwen 优雅降级，
  可选字段缺失时正文仍完整可读（这正是 `_render_slide_page` 对空值的处理路径）。

### 3.3 body 内容质量

两模型对表格页均**准确还原 Markdown 表格**（表头对齐、数据无丢失、无格式破坏），
正文可直接作为产物（无需二次渲染）。若后续需要 Qwen 也输出结构/概述，可在 prompt
中强化可选标记约束；当前设计以稳健优先，不强求。

### 3.4 局限

- 样例 PPT（`ai_market_10pp.pptx`）由脚本生成，**不含真实图表图片**，仅表格与文字——
  "数据型图表（柱状/折线/饼图）→ Markdown 表格"转译路径未充分覆盖，需后续含图样例验证。
- Qwen 通过本地 Gradio 适配器访问 HF Space ZeroGPU，单页延迟显著高于 GLM（本次两者均单次成功，
  未触发重试/降级，故限流差异未在本次暴露）。
